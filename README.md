# Uber-Analytics-Dashboard
Uber Analytics Dashboard using Power BI
**Project Overview**
An interactive Power BI dashboard developed to analyze Uber trip data and understand booking performance, revenue, customer ratings, trip distance, vehicle types, locations and monthly trends.

**Objectives**
- Analyze booking and revenue performance.
- Understand trip patterns across vehicle types and location.
- track key performance indicators and booking status.
- Identify trends in bookings, revenue, distance and ratings.

**Key Dashboard Metrics**
- Total Bookings
- Total Revenue
- Total Trip Distance
- Average Customer Rating
- Booking Status
- Vehicle Type Performance

**Dashboard Features**
- KPI cards for key business metrics
- Booking status analysis
- Revenue analysis
- Vehicle type analysis
- Location-wise analysis
- Trip distance analysis
- Customer rating analysis
- Monthly and Quarterly trend analysis
- Interactive slicers and filters
- Interactive visualizations for exploring trip performance
